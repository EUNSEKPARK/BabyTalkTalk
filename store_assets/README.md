# Store Assets 준비 가이드

이 폴더에 아래 파일들을 넣어주세요.

## 필수
- `app_icon_512.png` — 512×512 PNG (앱 아이콘, assets/app_icon.png 기반으로 리사이즈)
- `feature_graphic_1024x500.png` — 1024×500 PNG/JPG

## 스크린샷 (최소 2장, 권장 5~8장)
- `phone/` — 폰 스크린샷 (1080×1920 또는 1080×2400)
  - 채팅 입력 화면, 대시보드, 타임라인, 성장 일기, 통계 화면 등
- `tablet_7inch/` — 7인치 태블릿 (권장)
- `tablet_10inch/` — 10인치 태블릿 (권장)

## 팁
- 에뮬레이터에서 `flutter screenshot` 명령으로 캡처 가능
- Figma/Canva에서 베젤 프레임 + 설명 텍스트 추가하면 더 좋음
