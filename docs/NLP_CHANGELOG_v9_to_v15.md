## 버전별 변경 이력

### v10 (Day 1: 3/31) — 오타 내성 강화
- `_normalizeText`에 **오타 사전 55개** 체계적 추가 (수유14/이유식7/수면12/기저귀6/건강7/간식4/기타5)
- `feedingDuringSleepPattern` 확장 — "직수 5분만에 잠들어버렸어" 패턴
- `feedingVomitPattern` 신규 — "수유 후 게워냈어" → health 분류 + 건강 점수 부스트
- `typoMap` 12→24개로 확장

### v11 (Day 2: 4/1) — 의도/문맥 필터 고도화
- **의도 필터 7개 패턴** 추가 (정상/괜찮 질문, 맞나/맞는건지, 확인/연락 계획, 비교 질문, 소망 표현)
- **`hasStrongRecordData` 가드** — ml/cc/도/분 데이터가 있으면 의도 필터 우회
- **비기록 문장** 27→62개 (+35) 확장
- `other` 분류 시 `memo: trimmed` 추가 (원본 입력 보존)

### v12 (Day 3: 4/2) — 문맥감지 + 키워드 충돌 해결
- **Phrase-first 문맥 규칙** — XX스틱→snack, 퍼프/핑거푸드→snack, XX죽/미음/퓨레→babyfood 확정
- **Milestone 키워드 37개 추가** (30→67): 대운동, 소운동, 사회/인지, 언어, 치아 발달
- **Snack 키워드 9개 추가**: 핑거푸드, 퍼프, 웨이퍼, 크래커 등
- **과도한 띄어쓰기 복원 버그 수정** — 3연속→4연속 (시간접두사+키워드 정상 인식)
- **분리불안 예외 처리** — `(?<!분리)(걱정|불안|스트레스)` lookbehind

### v13 (Day 4: 4/3) — 테스트 대폭 확장 + 엣지 케이스
- **부정문 "자다가" 전환 패턴** — "안 자다가 겨우 잤어" → sleep 기록 인식
- **건강 키워드 5개 추가**: 중이염, 눈곱, 결막염, 아토피, 수족구
- **의도 필터 2개 패턴** — "늘려야/줄여야 하나", "어떻게 하지"
- **표현 풀 대폭 확장** (각 카테고리 +13~21개)
- **테스트 규모 10K→20K** (sentencesPerPersona 100→200)

### v14 (Day 5: 4/4) — 스코어링 엔진 구조 개선
- **Phrase-first 스코어링 엔진 리팩토링** — `_scoreCategory` 키워드를 길이 내림차순 정렬, 3글자+ 구문 매칭 시 하위 키워드 중복 스코어 차단 (`consumedSubstrings`)
- **3-seed 교차검증** 도입 (seed=42, 123, 777 → 변동성 0%)

### v15 (Day 6: 4/5) — 대규모 테스트 + 최종 키워드 보강
- **수면 키워드/패턴**: `잔다`(3.0), `통잠`(3.0), `눈\s*붙`(2.5) 추가
- **건강 패턴**: `열\s*(떨어|내려|나아)`(3.0), `접종\s*후`(2.5) 추가
- **마일스톤 패턴**: `이\s*\d+\s*개\s*(째|나)`(3.0) 추가
- **표현 풀 3차 확장** (~300개 표현)
- **테스트 규모 20K→50K** (sentencesPerPersona 200→500)

### Day 7 (4/6) — 최종 안정화
- **전체 회귀 테스트 통과**: v2(260), nlp_full(197), 50K×3seed, edge_cases(24)
- **엣지 케이스 전용 테스트** 신규 작성 (24 cases, 100%)
- **Threshold 2.0 최적** 확인 (자동저장 90.5%, 객관식 1.9%)
