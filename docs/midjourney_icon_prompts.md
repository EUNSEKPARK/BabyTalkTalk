## 미드저니 사용 팁

### 생성 후 후처리
1. **배경 제거**: 필요 시 remove.bg 또는 Photoshop으로 크림 배경 제거 → 투명 PNG로 변환
2. **크기 조정**: 512x512px 또는 1024x1024px로 리사이즈
3. **일관성 체크**: 모든 아이콘의 선 두께, 색감, 여백이 비슷한지 확인

### Seed 고정으로 통일감 확보
1. 첫 번째 아이콘을 만족스럽게 생성
2. `/describe` 또는 결과 이미지의 seed 값을 확인
3. 나머지 아이콘 프롬프트에 `--seed [값]` 추가하여 스타일 통일

### 일괄 생성 순서 추천
1. **분유(bottle)** 먼저 생성 → 기준 스타일 확정
2. 만족스러운 결과의 `--seed` 값 확인
3. 나머지 11개 아이콘에 동일 seed 적용
4. 필요 시 `--sref [이미지URL]` (Style Reference)로 첫 결과를 참조 이미지로 지정

### Style Reference 활용법
```
/imagine [프롬프트] --sref [첫번째_완성_아이콘_URL] --sw 100
```
- `--sw 100`: 참조 이미지의 스타일을 100% 따라감
- 이렇게 하면 12개 아이콘이 거의 동일한 화풍으로 생성됨
