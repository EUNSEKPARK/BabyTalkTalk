## Style Consistency Guide

### Visual Style Rules
1. **3D Clay Render** for character illustrations: `soft 3D clay render style, matte texture, rounded organic shapes`
2. **Flat Vector** for category icons: `minimal flat design, clean vector style, thick rounded strokes`
3. **Dark Background** always: `dark navy background (#1A1A2E)`
4. **Warm Glow** for accents: `subtle soft glow, warm pastel accents`
5. **No Outlines** on characters: keep soft and blobby
6. **Consistent Baby Character:** round head, dot eyes, small gentle smile, no nose, soft cheeks

### Midjourney Settings
- **`--s 200`** for illustrations (moderate stylization)
- **`--s 100`** for icons (cleaner, less artistic)
- **`--s 50`** for UI icons (maximum clarity)
- **`--v 6.1`** for all prompts
- **`--sref [URL]`** after generating baby avatar to lock character style

### Recommended Generation Order
1. **Baby Avatar Default** (#2) — establishes the character design
2. **Baby Avatar Variations** (#3) — lock style with `--sref`
3. **Splash Screen** (#6) — same character, vertical format
4. **Onboarding** (#5) — same character in scenes
5. **App Icon** (#1) — derived from character face
6. **Category Icons** (#4) — separate flat style, batch generate
7. **Empty States** (#7, #8, #9) — same character, different contexts
8. **Remaining** (#10–#14) — decorative and supplementary

### Post-Processing Notes
- Category icons (#4): Remove backgrounds and ensure perfect circles using image editing tools
- Tab icons (#15): Recommended to recreate as SVG in Figma for pixel-perfect rendering
- All character illustrations: May need slight contrast adjustment to pop against `#1A1A2E` dark UI
- Export all images as PNG with transparency where applicable
