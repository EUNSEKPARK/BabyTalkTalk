## 사용 팁

1. `--s` (stylize) 값을 높이면 더 예술적, 낮추면 더 프롬프트에 충실
2. `--v 6.1` 대신 `--niji 6`을 사용하면 더 애니메이션/일러스트 느낌
3. 아이콘류는 `--ar 1:1`, 화면 배경은 `--ar 9:16` 또는 `--ar 16:9` 사용
4. 투명 배경이 필요하면 생성 후 배경 제거 도구 사용 (remove.bg 등)
5. 앱 내 일관성을 위해 같은 세트는 한번에 생성하는 것을 추천
